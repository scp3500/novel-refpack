# 高阶创作模式与提示词指南

本项目支持五种工作模式：同人/IF 合并参考包、纯文风脱敏原创、多文风混搭、反 AI 腔过滤，以及群聊/贴吧人设蒸馏。

---

## 模式 1 · 同人与 IF 线完整参考包（默认）

### 一键命令
```bash
python scripts/13_build_pack.py --preset standard --ratio 0.70
```

产出 `work/out/参考包.md`（默认总计 ~150 KB / ~4 万 tokens，**70% 文风例子 + 30% 整书总结**）：
- **上半部（锁事实）**：`〇 续写/IF 速查区`（硬设定、结局现状、卷末状态卡、分歧点）+ `上篇 总览` + `下篇 分卷脉络`（超预算时优先保全开篇与最后 2 卷状态快照）；
- **下半部（锁文风）**：紧贴用户写作指令，放置高密度叙述腔、连续动作白描、五感细节、对白呼吸感、角色语音档案与零频黑名单。

## 模式 2 · 纯文风抽取与原创写作（`--style-only --anonymize`）

### 适用场景
写一个全新的原创世界观与新主角，只想借用某位成熟作家的叙述腔调、动作节奏、环境细节与对白张力，**绝不想带入原书剧情、副本设定或角色名**。

### 一键命令（免 API、秒级出稿）
```bash
python scripts/12_run_all.py --style-only --anonymize --preset standard
# 或自定义大小，如 80KB（约 2.1 万 tokens）
python scripts/12_run_all.py --style-only --anonymize --kb 80
```

### 做了哪些隔离处理
1. 跳过分片摘要、卷纪要与整书总结；
2. 剔除分剧本语料、名场面台词、原书章节标题与角色关系卡；
3. 台词改按**话语功能桶**（命令禁止、让步接受、反问逼问、抱怨吐槽、慌乱结巴等）展示句法与句尾口癖；
4. 原书角色名自动脱敏为中性代称（`某甲 / 某乙 / 某丙`），`【条目框】` 替换为「某技能/条目」；
5. 篇幅集中分配给**细粒度笔法与镜头细节**（连续动作白描、五感与光影切镜、对话穿插神态锚点、转场留白）、叙述句长阶梯与搭配雷区，减少 AI 反复复读同一类描写。

## 模式 3 · 多文风混搭（跨书融合）

分别对作品 A 与作品 B 运行 `--style-only --anonymize --kb 60`，从两份 `纯文风包.md` 中按维度拼接：
- **叙述骨架与动作推进（取作品 A）**：截取 A 的「叙述腔」「细粒度笔法与镜头细节（连续动作/五感）」；
- **对白节奏与吐槽口癖（取作品 B）**：截取 B 的「对白回合片段」「语体与台词功能范例」；
- **冲突约束**：明确要求「无论对白多么轻松跳脱，旁白叙述必须保持作品 A 的冷硬克制节奏」。

## 模式 4 · 反 AI 腔与特征过滤（Anti-AI De-flavouring）

### 方法 1：从《例子.txt》或《纯文风包.md》直接取用黑名单
文风包底部自带：
- **搭配表 · 典型 vs 雷区**：全书 0 次出现的动词/方位搭配标为 `【禁用】`；
- **零频黑名单**：原作者从不使用的典型 AI 套话词；
- **使用禁令 / 常见误区**：`config/bans.md` 提供的通用反 AI 腔与动作视点纪律。

### 方法 2：开箱即用负面约束模板
```markdown
【反 AI 腔负面约束 Negative Constraints】
1. 禁用词汇与搭配：严禁出现「眼神深邃」「眼神复杂」「嘴角勾起弧度」「倒吸凉气」「指节发白」「仿佛凝固」。
2. 禁用公文辩证句型：严禁「不仅……更是……」「与其说……不如说……」「不是……而是……」，直接陈述事实。
3. 严禁强行升华：动作或对话结束即收尾，禁止章节末段添加总结性、哲理性抒情旁白。
4. 动作与施动者落地：单句承载单一具体动作，禁止无主语的器官或物件悬空动作。
```

## 模式 5 · 群聊与贴吧人设蒸馏（Chat Mode）

```bash
# 在线抓取贴吧热门帖并蒸馏（需 pip install aiotieba）
python scripts/chat_run.py --tieba 弱智吧 --no-llm

# 从本地导出 JSON / QQ 聊天记录蒸馏（支持自定义 work_dir）
python scripts/chat_run.py --config config/chat.json
```

工具会自动统计消息字数分位数（P50/P80/P95）、每千字句号率与空格断句习惯、高频句首发语词与行为交互逻辑，并按实测句号频率动态生成标点规则。
