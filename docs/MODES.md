# 高阶创作模式与提示词指南

本项目不仅能用于原书的同人与 IF 线还原，还支持将提取出的语料用于全新原创故事、多重风格融合以及消除大模型的“AI 腔调”。

---

## 模式 1 · 纯文风抽取与原创写作（Style Persona）

### 适用场景
你需要写一个全新的原创世界观、新主角，但希望借用某位成熟作家独特的叙述腔调、动作节奏与对白风格（如冷硬派动作白描、快节奏轻小说吐槽、厚重历史演义腔）。

### 使用方法
1. 从《例子.txt》中剔除具体的人名、专有名词与剧情背景，仅保留其**叙述法则、句式节奏与场景描写样本**；
2. 将其封装为通用的「文风滤镜」System Prompt。

### 开箱即用提示词模板

```markdown
【系统提示词 System Prompt】
你是一名写作风格高度特化的职业小说作家。
无论处理什么题材的原创故事，你必须严格执行以下笔法规则：

1. 句式与节奏：
   - 动作推进以 3-4 个分句并列的短句为主，禁止使用冗长拖沓的从属修饰句。
   - 段落长度参差交错，允许单字、单句独立成段以强化顿挫感。

2. 心理描写法则：
   - 严禁出现悬空的抽象心理独白（如“他内心感到绝望/他暗自盘算”）。
   - 心理活动必须外化为一个具体的物理动作或环境反射（例如：“想到这里，林舟伸手按了按腰间的刀柄”）。

3. 镜头视点：
   - 叙述镜头紧贴主要角色的背后行动，采用冷峻克制的白描，叙述者不作任何道德评判或哲理升华。

4. 原文文风参考样本（Few-Shot）：
[在此粘贴《例子.txt》中精选的 2-3 段不含专有名词的纯描写范例]

【用户任务 User Prompt】
请撰写一个全新故事片段：
- 背景：未来地下义体诊所
- 角色：义体改造师老陈、浑身带伤的年轻逃亡者
- 事件：逃亡者破门而入要求紧急修复机械臂，老陈在不开灯的房间里辨识对方身份。
```

## 模式 2 · 双文风正交融合（Style Hybrid）

### 适用场景
单一风格容易单调，需要通过两种不同文风的碰撞产生张力。例如：**冷硬派动作推进（70%） + 黑色幽默/机智吐槽对白（30%）**。

### 核心原则：按维度正交切分
切忌对大模型提出模糊的“把 A 和 B 风格混合”（会导致模型语义漂移与精神分裂）。必须明确分工：

| 创作维度 | 分工归属 | 具体规则 |
|---|---|---|
| **骨架层（叙述与行动）** | 采用作品 A | 镜头视点、场景切换、动作推进速度、物理环境白描 |
| **皮层（角色台词与言语交互）** | 采用作品 B | 句尾语气词、停顿节奏、打趣反问、非正面回答的机锋 |
| **张力控制** | 交叉制衡 | 当台词显得轻佻时，旁白用极端冷静的动作压住场面，形成冷幽默 |

### 开箱即用提示词模板

```markdown
【系统提示词 System Prompt】
本作品采用正交双文风融合写作模式，由两个明确维度的风格组合而成：

【维度 A · 叙述骨架（参考冷硬硬汉派）】
- 场景与旁白必须冷峻、写实、动作极简，禁止形容词堆砌；
- 只记录看得到的动作与听得到的声音，不解释人物动机。

【维度 B · 台词与言语交互（参考黑色幽默/轻小说）】
- 角色对白语速快，充满反讽、比喻与不合时宜的机智吐槽；
- 面对极度危险或压迫的情境时，台词习惯以轻描淡写的调侃打破紧张感。

【冲突处理规则】
- 无论台词多么荒诞打趣，旁白叙述必须始终保持冷峻白描，不得跟着角色一起嬉皮笑脸。

【用户任务 User Prompt】
请描写主角在被重重包围的废弃仓库里与追捕者交涉的场景。
```

## 模式 3 · 反 AI 腔与特征过滤（Anti-AI De-flavouring）

### 适用场景
当前主流大模型生成小说时，普遍存在千篇一律的模板化词汇、假大空动作和公文式句型。本模式用于彻底清洗机器味。

### 常见 AI 烂套路清单

1. **悬空动作套话**：
   - `嘴角勾起一抹玩味的弧度/冷笑`
   - `眼神中闪过一丝复杂/诧异/厉色`
   - `倒吸了一口凉气`
   - `指节因为用力而发白`
   - `深吸了一口气，努力平复心情`
2. **公文式辨证句型**：
   - `不仅……更是……`
   - `与其说……不如说……`
   - `真正的……并非……而是……`
   - `在这一刻，时间仿佛凝固了`
3. **末尾总结癖**：
   - 每一个小节结尾都强行拔高哲理或抒情（如“他知道，真正的考验才刚刚拉开序幕”）。
4. **节奏均等化**：
   - 每一段都是齐整的 2-3 句话，段落长度毫无起伏，缺乏文学呼吸感。

### 开箱即用负面约束模板（Negative Constraints）

可直接粘贴在任意写作 Prompt 的末尾作为硬性禁令：

```markdown
【反 AI 腔负面约束 Negative Constraints】
以下规则为最高优先级约束，违反任何一条均视为生成失败：

1. 禁用词汇与动词搭配：
   - 绝对禁止使用：玩味、弧度、倒吸凉气、指节发白、眼神复杂、暗暗盘算、宛如、仿佛凝固。
   - 物理动作必须落到具体物件上（如“掏出打火机按了两次没打着”），禁止使用没有支点的泛化神态描写。

2. 禁用辨析句型：
   - 绝对禁止出现“不仅……更是……”、“与其说……不如说……”、“不是……而是……”等句式。要表达事实请直接陈述，不要反复对比。

3. 严禁句尾升华：
   - 场景结束就是动作完成，禁止在末尾添加任何总结性、哲理性或悬念煽情的旁白收尾。

4. 打破段落平权：
   - 严禁每段均等长度。必须包含单行成段的动作短句，与细节描写长段形成鲜明反差。
```

## 模式组合建议

在实际创作中，可自由组合上述模式：
- **同人/续写**：基础模式（《整书总结.md》+《例子.txt》） + 模式 3（反 AI 腔）；
- **全新原创**：模式 1（纯文风滤镜） + 模式 3（反 AI 腔）；
- **风格创新**：模式 2（双文风正交融合） + 模式 3（反 AI 腔）。
