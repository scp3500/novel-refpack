# 高阶创作模式与提示词指南

本项目不仅能用于原书的同人与 IF 线还原，还支持将语料用于全新原创故事、多文风混搭以及消除大模型的“AI 腔调”。

---

## 模式 1 · 纯文风抽取与原创写作（Style Persona）

### 适用场景
你需要写一个全新的原创世界观、新主角，但希望借用某位成熟作家的叙述腔调、动作节奏与对白风格（如冷硬派动作白描、快节奏吐槽、厚重历史演义腔）。

### 使用方法
1. 从《例子.txt》中剔除具体的人名、专有名词与剧情背景，仅保留其**叙述节奏、对白习惯与场景描写样本**；
2. 将其作为通用的写作风格滤镜，直接粘贴到提示词中。

### 提示词模板

```markdown
【系统提示词 System Prompt】
你是一名文字风格鲜明的职业小说作家。
无论写什么题材的原创故事，必须严格执行以下笔法规则：

1. 句式与节奏：
   - 动作推进以 3-4 个分句并列的短句为主，少用冗长拖沓的复合长句。
   - 段落长度长短交错，允许单字、单句独立成段以强化停顿节奏。

2. 心理描写法则：
   - 严禁出现悬空的抽象心理独白（如“他内心感到绝望/他暗自盘算”）。
   - 心理活动必须外化为一个具体的物理动作或环境反射（例如：“想到这里，老陈伸手按了按腰间的扳手”）。

3. 镜头视点：
   - 叙述镜头紧贴主要角色的行动，采用冷静克制的白描，叙述者不作任何道理说教或哲理升华。

4. 原文文风参考样本：
[在此粘贴《例子.txt》中精选的 2-3 段不含原著人名的纯描写范例]

【用户任务 User Prompt】
请撰写一个全新故事片段：
- 背景：未来地下义体诊所
- 角色：义体改造师老陈、浑身带伤的年轻逃亡者
- 事件：逃亡者破门而入要求紧急修复机械臂，老陈在不开灯的房间里辨识对方身份。
```

## 模式 2 · 多文风混搭（跨书融合）

### 适用场景
单一风格容易单调，需要通过两种不同文风的碰撞产生张力。例如：**A 书的冷硬动作推进 + B 书的幽默日常拌嘴/吐槽**。

### 核心原则：按维度明确分工
切忌对大模型提出模糊的“把两本书风格混合”（会导致模型语义漂移）。必须明确分工：

| 创作维度 | 分工归属 | 具体规则 |
|---|---|---|
| **叙述骨架（行动推进）** | 采用作品 A | 镜头视点、场景切换、动作推进速度、物理环境白描 |
| **对白与交互（角色说话）** | 采用作品 B | 句尾语气词、停顿节奏、日常拌嘴、非正面回答的机锋与口癖 |
| **张力控制** | 交叉制衡 | 当对白显得轻松打趣时，旁白叙述始终保持冷静，形成冷幽默反差 |

### 提示词模板

```markdown
【系统提示词 System Prompt】
本作品采用双文风混搭模式，由两个明确维度的风格组合而成：

【维度 A · 叙述与动作（参考作品 A）】
- 场景与旁白必须冷峻、写实、动作极简，禁止形容词堆砌；
- 只记录看得到的动作与听得到的声音，不解释人物动机。

【维度 B · 角色对白（参考作品 B）】
- 角色对白语速快，充满吐槽、反问与生动的口癖；
- 面对紧张情境时，习惯用日常打趣的口吻说话。

【冲突处理规则】
- 无论角色对白多么打趣，旁白叙述必须始终保持冷静白描，不得跟着角色一起浮夸。

【用户任务 User Prompt】
请描写主角在被重重包围的废弃仓库里与追捕者交涉的场景。
```

## 模式 3 · 反 AI 腔与特征过滤（Anti-AI De-flavouring）

### 适用场景
当前大模型写小说时，普遍存在千篇一律的套话词汇、悬空神态和公文式句型。本模式用于彻底洗掉机器味。

### 怎么得出反面例子（两种实操方法）

#### 方法 1：直接把一段典型 AI 水文贴给模型提炼
平时模型写出了满篇机器味的小说段落时，直接复制一段贴给 AI，发如下指令：
> “下面这段文本充满典型的 AI 水文特征。请帮我挑出里面所有的机器味套话（如‘嘴角勾起弧度’、‘眼神复杂’、‘倒吸凉气’、‘不仅更是’），整理出一份【反向例子与绝对禁用清单】。”

AI 提取出的清单，就是最针对当前模型的“杀毒软件”。

#### 方法 2：直接使用《例子.txt》底部的零频黑名单
原著小说中作者一辈子都没用过的词，往往就是大模型最爱滥用的套话。直接把《例子.txt》末尾的零频词与搭配禁区拿来当负面提示词。

---

### 开箱即用负面约束模板（可直接粘贴在提示词末尾）

```markdown
【反 AI 腔负面约束 Negative Constraints】
以下规则为最高优先级约束，违反任何一条均视为生成失败：

1. 禁用词汇与动词搭配：
   - 绝对禁止使用：玩味、弧度、倒吸凉气、指节发白、眼神复杂、暗暗盘算、宛如、仿佛凝固。
   - 动作描写必须落实到具体的物品操作上（如“掏出打火机按了两次没打着”），禁止使用没有实物支撑的悬空神态。

2. 禁用公文式辩证句型：
   - 绝对禁止出现“不仅……更是……”、“与其说……不如说……”、“不是……而是……”等句式。要表达事实请直接陈述，不要反复对比。

3. 严禁结尾强行升华：
   - 场景结束就是动作完成，禁止在章节末尾添加任何总结性、哲理性或强行制造悬念的抒情旁白。

4. 打破段落均等节奏：
   - 严禁每段均等长度。必须包含单行成段的动作短句，与细节描写长段形成鲜明反差。
```

## 模式组合建议

在实际创作中，可自由组合上述模式：
- **同人/续写**：基础模式（《整书总结.md》+《例子.txt》） + 模式 3（反 AI 腔）；
- **全新原创**：模式 1（纯文风滤镜） + 模式 3（反 AI 腔）；
- **风格创新**：模式 2（双文风混搭） + 模式 3（反 AI 腔）。
