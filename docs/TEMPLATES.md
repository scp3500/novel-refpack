# 模板规范与产物骨架

本文档定义各阶段摘要提示词的结构化契约、四类输出产物的标准骨架，以及下游写作 Prompt 组合方式。

---

## 1. 摘要结构化契约

### 一层分片摘要（`config/prompts/stage1_note.txt`）
```markdown
- 章节范围：[起止章节与标题]
- 叙述人称与视角：[第一人称 / 第三人称 / 视点切换说明]
- 时间线锚点：[当前剧情处于全书的时间节点与阶段]
- 主要剧情：[按序输出 10-18 条事件，单条包含「主语-行为-结果」]
- 出场角色与关系变动：[本片登场人物及其人际关系推进]
- 设定与术语：[新出现的地理、组织、道具、能力机制等]
- 类型桥段：[喜剧 / 日常 / 战斗 / 感情 / 沉重比重与代表场面]
- 伏笔与线索：[埋下的悬念或前期线索的回应]
- 原文文风样本：[3-6 条逐字摘录的原句，标明类别]
- 基调一句话：
```

### 二层分卷纪要（`config/prompts/stage2_volume.txt`）
```markdown
# [卷名/章节名]
## 一、范围与时间锚
## 二、剧情纪要（20-40 条关键事件）
## 三、本篇末角色状态快照（写 IF 线与续写定位的核心锚点）
## 四、登场人物（新登场请标注）
## 五、设定 / 地点 / 组织 / 术语
## 六、名场面与关键台词（逐字照抄）
## 七、伏笔与回收
## 八、基调一句话
```

## 2. 交付产物骨架

### A. 《整书总结.md》（`work/out/整书总结.md`）
顶部带 `> 容量统计：...` 看板，按三级优先级保序组织：
```markdown
# 《书名》整书总结（事实圣经）
> 容量统计：大小 XX.X KB ｜ 字符 XX,XXX ｜ 估算 ~XX,XXX tokens ｜ ...

〇 续写 / IF 创作速查区（Priority 1，优先 100% 保留）
   0.1 硬设定速查（不可改）
   0.2 结局现状
   0.3 角色状态卡（截至结局）
   0.4 IF / 续写分歧点
   0.5 禁区（来自 bans_file 或 config/bans.md）
上篇 · 总览（Priority 2）
   一、作品定位与核心看点
   二、世界观与核心设定
   三、势力阵营
   四、主要角色档案
   五、文风与写作规则（实测硬指标）
下篇 · 分篇详细剧情（Priority 3，超预算时首尾卷高权保留+单卷首尾快照留存）
附录（Priority 2）
   A 角色线 / 关系线 / 群像
   B 设定术语词典
   C 伏笔与回收
```

### B. 《例子.txt》（`work/out/例子.txt`，共十六节）
顶部带 `> 容量统计：...` 看板，按以下十六节组织（`--style-only` 纯文风模式下自动剥离第八、十、十三、十五节，第六节转为去角色绑定的话语功能桶）：
```markdown
## 一 · 文风速览（统计靶）
## 二 · 叙述腔（超短句 / 短句 / 中句 / 长复合句阶梯）
## 三 · 内心独白 / 吐槽（及独立成段短句）
## 四 · 细粒度笔法与镜头细节（连续动作白描 / 五感环境 / 对话穿插动作 / 转场 / 收尾留白）
## 五 · 对白回合片段（按场景分类的引号与叙述呼吸节奏）
## 六 · 台词分角色 + 语音档案（--style-only 下为「语体与台词功能范例」）
## 七 · 亲密与感情场景写法（含场景词典）
## 八 · 名场面原文摘录（--style-only 跳过）
## 九 · 描写套路（18 类意图完整句群）
## 十 · 语音分期（--style-only 跳过）
## 十一 · 搭配表 · 典型 vs 雷区（18 类高频搭配 + 零频黑名单）
## 十二 · 用词表与场景高频词
## 十三 · 章节标题样例（--style-only 跳过）
## 十四 · 专项摘录（--style-only 下采用纯文学通用主题）
## 十五 · 分剧本语料（--style-only 跳过）
## 十六 · 使用禁令 / 常见误区（置于文末作收口自检）
```

### C. 《参考包.md》（`work/out/参考包.md`）与《纯文风包.md》（`work/out/纯文风包.md`）
- **《参考包.md》**：顶部展示总 KB、字符数、估算总 Tokens 与「例子 : 摘要」实际占比；上半部为《整书总结》（自动将重复的 `0.5 禁区` 折叠为指向文末清单的指引以省 Token），下半部为《例子集》紧贴用户写作 Prompt。
- **《纯文风包.md》**：仅在 `--style-only` 下生成，只包含脱敏后的纯文风参考与统计看板，零剧透、零设定污染。
