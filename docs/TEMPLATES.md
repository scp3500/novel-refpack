# 模板规范与产物骨架

本文档定义各阶段摘要提示词的结构化契约、最终两份产物的标准骨架，以及面向下游大模型写作的标准 Prompt 模版。

---

## 1. 摘要结构化契约

### 一层分片摘要（`config/prompts/stage1_note.txt` 规范）

模型在 Stage 2 生成的单片摘要需严格包含以下结构化字段：

```markdown
- 章节范围：[起止章节与标题]
- 叙述人称与视角：[第一人称 / 第三人称 / 视点切换说明]
- 时间线锚点：[当前剧情处于全书的时间节点与阶段]
- 主要剧情：[按序输出 10-18 条事件，单条包含「主语-行为-结果」]
- 出场角色与关系变动：[本片登场人物及其人际关系推进]
- 设定与术语：[新出现的地理、组织、道具、能力机制等]
- 桥段分布：[日常、战斗、悬疑、情感等比重及代表场面]
- 伏笔与线索：[埋下的悬念或前期线索的回应]
- 原文文风样本：[3-6 条逐字摘录的原句，标明类别]
- 基调概述：[单句概括本片情绪色彩]
```

### 二层分卷纪要（`config/prompts/stage2_volume.txt` 规范）

Stage 5 基于分片摘要合并提炼的卷级档案：

```markdown
# [卷名/章节名]
## 一、范围与时间锚点
## 二、主干剧情脉络（20-40 条关键事件）
## 三、卷末角色状态快照（写 IF 线与续写定位的核心锚点）
## 四、登场人物表（首次登场需标明）
## 五、设定 / 地理 / 阵营 / 关键道具
## 六、名场面与核心台词（原文摘录）
## 七、伏笔推进与闭环
## 八、本卷主基调
```

## 2. 交付产物骨架

### 《整书总结.md》（`work/out/整书总结.md`）

用于约束剧情事实，结构自顶向下逐层展开：

```markdown
〇 续写 / IF 创作速查区（必须置顶）
   0.1 硬设定速查表（不可违背的基础设定）
   0.2 结局现状卡（收尾时各角色坐标、生存状态与主线停顿点）
   0.3 关键角色终局状态表
   0.4 核心分歧点候选（IF 线介入契机）
   0.5 严禁触碰的剧情禁区（来自 bans.md）
上篇 宏观总览
   一、作品定位与核心看点
   二、世界观与规则设定
   三、势力阵营与利益关系网
   四、主要角色档案（含人际称呼与语气基调）
   五、文风量化特征与写作规范
下篇 分卷详细脉络
   [逐卷收纳全事件记录与卷末状态快照]
附录
   A 角色支线与群像发展轨迹
   B 专有术语与专有名词词典
   C 伏笔与回收总览
```

### 《例子.txt》（`work/out/例子.txt`）

用于对齐语言风格，提供经过验证的原作语料样本：

```markdown
第一节 使用禁令与常见误区（来自 config/bans.md）
第二节 文风特征速览（边际统计与基准量化靶标）
第三节 叙述腔调范例（短句、中句、长句原句摘录）
第四节 内心独白与心理活动范例
第五节 对白回合片段（按日常、冲突、审讯等场景分类）
第六节 分角色台词与语音档案（各角色自称、称谓、口癖与典型句式）
第七节 重点情感与氛围场景写法
第八节 名场面原文摘录
第九节 典型意图描写套路（如神态、动作连贯性描写）
第十节 角色语音随时间线的演变轨迹
第十一节 搭配表与零频黑名单（典型搭配与禁止使用的错误搭配）
第十二节 高频用词表与场景专属词汇表
```

## 3. 下游调用 Prompt 模板

通过组合《整书总结》与《例子集》的部分章节，向模型下发写作任务。

### 模版 1：剧情续写 / 番外生成

```markdown
[背景事实参考]
从《整书总结》中提取：
- 「〇 续写 / IF 创作速查区」
- 对应卷的「卷末角色状态快照」及出场角色档案

[语言风格参考]
从《例子集》中提取：
- 「第一节 使用禁令」
- 「第三节 叙述腔调范例」
- 本次场景对应的「第五节 对白片段」与「第十一节 搭配表」

[写作任务]
- 任务目标：续写一段[具体事件/场景]。
- 时间定位：[指定卷名/章节之后]。
- 视角：[指定视角角色及人称]。
- 字数：约 [字数] 字。
- 约束要求：严格遵守使用禁令，角色语气严格匹配语音档案，不得凭空引入未存在的设定机制。
```

### 模版 2：IF 分歧线推演

```markdown
[分歧介入定义]
- 介入节点：选取《整书总结》附录 C 或指定章节中的分歧点：[具体事件]。
- 改变要素：将原事件走向修改为：[改变内容]。
- 初始状态：对齐该节点对应卷的「卷末角色状态快照」，不可使用最终结局状态。

[推演要求]
- 分析本次变动对相关角色的连锁影响（心境、立场、人际关系）。
- 输出后续情节大纲与关键场景演化，确保新展开符合世界观与角色性格底线。
```

### 模版 3：系统级文风约束注入

将提取出的规则作为 System Prompt 输入给通用写作助手：

```markdown
你是一个文本生成助手，写作时必须严格遵守以下负向清单：
1. 词汇与搭配禁区：严禁使用以下零频黑名单词汇及禁用搭配：
   [填入例子集第十一节与第十二节的黑名单列表]
2. 句式约束：
   - 动作描写单句承载单一动作，避免无主语的被动移位句式。
   - 空间距离采用具体感官后果描述，避免机械量化数字。
   - 角色发言严格对齐其身份自称与专有称谓。
```
