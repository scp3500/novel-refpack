# 模板与成品骨架

## 1 · 一层摘要模板（`config/prompts/stage1_note.txt`）

```
- 章节范围：写清首尾标题
- 叙述人称与视角：第一人称 / 第三人称 / 视点切换
- 时间线锚点：大约在全书什么位置、主角处于哪个阶段
- 主要剧情：按时间顺序 10-18 条，每条一句话，含关键人名与结果
- 出场角色与关系变化
- 设定 / 术语 / 地理 / 组织
- 类型桥段：喜剧 / 日常 / 战斗 / 感情 / 沉重 各自比重与代表场面
- 伏笔与线索
- 原文文风样本：3-6 条，逐字摘抄，注明类别
- 基调一句话
```

模板定死之后再开跑。格式不统一 = 后面没法机械合并。


## 3 · 整书总结骨架（`work/out/整书总结.md`）

```

   0.1 硬设定速查（不可改）
   0.2 结局现状（停在哪儿、此刻谁在哪在干什么）
   0.3 角色状态卡（截至结局）
   0.4 IF / 续写分歧点
   0.5 禁区
上篇 总览
   一 作品定位与核心看点
   二 世界观与核心设定
   三 势力阵营
   四 主要角色档案（含称呼速查表）
   五 文风与写作规则（实测硬指标）
下篇 分篇详细剧情
   逐卷保留全部事件 + 每卷篇末状态快照
附录
   A 角色线 / 关系线 / 群像
   B 设定术语词典

```

## 5 · 拿这两份文件怎么用（提示词骨架）

**① 续写 / 番外**

```
[事实]  <整书总结 · 〇 速查区整段粘贴>
[文风]  <例子集 · 使用禁令 + 文风速览 + 对应场景的片段>
[任务]  写一段……。时间锚在<第 N 卷 / 某事件之后>，视角<谁>，约<字数>。
[禁区]  按例子集的禁令执行，不得发明世界观。
```

**② 写 IF 线**

先定节点（整书总结 〇.4 或附录 C 的分叉点），再对齐那一刻的状态：

```
分歧点：<哪一卷哪件事>，改成<什么>。
时间锚：用<那一卷>篇末的角色状态快照，别用结局状态。
要求：推蝴蝶效应，写清影响哪几个人、哪些设定。
```

**③ 给写作助手加风格约束**

把例子集的「写作规矩」和「零频黑名单」直接抄进系统提示词，当负面清单用：

```
禁止出现以下词（本书全书 0 次）：<零频黑名单>
一句只写一个动作；距离写后果不写数字；同一比喻全篇只出现一次。
摘抄原句必须连主语一起摘。
```

**④ 验收一段生成文本**

```bash
python scripts/11_verify.py --text 稿.txt --ref-pattern '(同类场景关键词)'
```

- 逐句 z 负得越多 = 越平淡（信息量低、用词太泛）；
- 正得越多 = 越生造（搭配是编的）；
- 0 频探针倍数 > 1.3 就是新造搭配太多，回去改。

**⑤ 让它开口说话前先查**

写之前跑 `query.py --who <角色> --func <处境>`，
把真实台词样本贴进提示词当参照，比写「请保持某角色的语气」有用得多。
