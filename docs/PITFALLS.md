# 指标目标与常见问题排查

本文档归纳流水线各阶段的指标预期目标、执行中可能遭遇的工程异常及排查方法，并说明文风统计维度的有效性边界。

---

## 1. 核心量化指标基准

### 文风验收四层指标（`scripts/11_verify.py`）

| 指标层级 | 检验对象 | 预期目标 | 诊断说明 |
|---|---|---|---|
| **0 频探针倍数** | 新造字符 4-gram 比率与原作基准的比值 | **$\le 1.05$** | 核心拟合指标。高于 1.30 说明生成文本使用了大量原作未出现的非常规字词组合与搭配。 |
| **逐句条件归一化 $z$ 分数** | 逐句字符 4-gram 匹配度（台词与叙述分算） | **均值处于 $\pm 0.3$ 区间** | 贴近 0 表示语感与原作吻合；显著偏负表示用词过于宽泛平淡；显著偏正表示用字生僻生造。 |
| **结构比值** | 相邻段落实词重合衰减度（自打乱比值） | 接近同类语料中位数 | 用于探测段落承接连贯性。样本量较小时波动较大，作为辅助参考。 |
| **门槛层** | 平均句长、对白占比、段落字数分布 | 全部落在同类参考段区间内 | 宏观尺寸筛选。仅用于校验篇幅比例是否失衡，不反映文本风格深层特征。 |

### 产物规模与覆盖率基准

| 检查项 | 目标区间 | 说明 |
|---|---|---|
| 单分片摘要字数 | 1,500 - 3,000 字 | 过短说明情节抽取得过于粗略；过长会超出下游二层归纳的上下文容量。 |
| 单卷纪要字数 | 1,800 - 3,500 字 | 确保收录卷内全部主干事件与伏笔闭环。 |
| 片尾特征词覆盖率 | 命中率 $> 25\%$ | `scripts/03_merge_notes.py` 自动化检测，用于防范长文本模型跳读。 |

## 2. 流水线常见问题排查

### 文本抽取阶段（Stage 0）

- **非正文文本混入**：
  - *现象*：高频词表中出现排版制作、网络发布声明或插图说明字符。
  - *排查*：检查 `config/project.json` 中的 `drop_headings`，补全需要直接丢弃的无正文目录名（如「制作信息」「插图目录」）。
- **标题层级丢失**：
  - *现象*：抽取后正文缺失 `#`, `##` 等 Markdown 标题标记，后续切片无法定位章节。
  - *排查*：EPUB 或 DOCX 原文可能采用了正文粗体段落而非标准 H 标签。检查 `scripts/00_extract.py` 解析逻辑，根据源文件特征添加样式类名匹配分支。

### 语义分片阶段（Stage 1）

- **跨版块混合切片**：
  - *现象*：主线章节与番外外传被切入同一个 `chunk_NN.txt`，导致摘要视点割裂。
  - *排查*：确认外传等独立章节在 `_all.txt` 中是否使用了一级标题（`#`）。分片脚本默认禁止跨越一级标题切分。

### 模型摘要阶段（Stage 2 & Stage 5）

- **模型跳读与截断漏读**：
  - *现象*：分片摘要中缺失后半截剧情；Stage 3 校验报错并给出片尾特征词未命中警告。
  - *排查*：部分模型单次输出窗口受限或长文本注意力稀释。可降低 `chunk_chars` 参数重切更小分片，或使用 `--only` 单独对异常分片进行补跑。
- **原文摘录被二次润色**：
  - *现象*：摘要中「原文文风样本」包含非原作书写习惯的模型合成腔调。
  - *排查*：抽查几份 `work/notes/chunk_NN.md`，通过全文检索核对原句是否逐字一致。提示词中需保持「严禁润色改写」的硬性约束。
- **输出格式漂移导致合并失败**：
  - *现象*：二层归纳报错找不到特定章节，或无法提取卷末角色快照。
  - *排查*：检查多路并发日志，确认是否存在部分模型跳过 Markdown 标题层级直接输出段落的情况。提示词模版中的字段标签必须与抽取脚本严格对齐。

### 汇总与去重阶段（Stage 3 & Stage 9）

- **剧情过度去重**：
  - *现象*：跨卷反复提及的同一历史事件在生成整书总结时被误删。
  - *排查*：清洗脚本仅应去重同一卷内的完全重复段落，跨卷事件需全部保留以维持各卷时间线的独立完整性。

## 3. 文风统计的有效性边界

在分析与验收阶段，应明确各量化指标的技术边界：

1. **宏观边际统计对顺序免疫**：
   平均句长、对白占比、段长等宏观汇总指标仅衡量文本密度与体裁外壳。即使将一段文章的所有段落完全打乱，这些指标均不会发生变化。因此门槛层指标仅用于排除明显的格式偏差，不能直接判定文风是否符合原作。
2. **搭配关系是文风的关键载体**：
   文本生成中的违和感往往源自常见动词与方位词的非典型组合。通过 `colloc.json` 统计高频动宾与方位搭配，并排查语料中频次为 0 的异常搭配，是识别文本是否地道的核心手段。
3. **对照组必须做场景切分**：
   全书整体平均值会平滑掉具体场景的写作特征（例如战斗段落均长往往显著短于日常与说教段落）。执行 `scripts/11_verify.py` 时必须传入 `--ref-pattern` 指定当前场景的特征词，与语料库内的同类片段进行区间对标。
4. **新专有名词的干扰与平替**：
   生成文本中新增的角色名、地名等专有词汇会天然抬高 0 频探针数值。验收脚本内置了专名探测机制，计算时会将新专名替换为原作等长专名后再行打分。
