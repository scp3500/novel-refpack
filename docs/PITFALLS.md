# 常见坑与指标目标

## 一、方法层面的坑

1. **拿边际统计判「像不像」。** 句长、对白占比、段长这些把整段打乱都测不出差别（AUC 0.500），
   只能当筛子。能测「像不像」的只有逐句层（字符 n-gram）和搭配表。
2. **不设「内容保留打散」这个负样本。** 没有负样本，任何指标都没法校准。
   做法：把语料段落原样打乱再拼回去 —— 同词同句同长度，只有顺序变。
3. **只查词表不查搭配表。** 写手很少造词，但经常配错动词和方位。
   `推开` 121 次是对的，`一把推开` 0 次；`眼疾手快` 14 次，`手快` 单用不是这本书的说法。
4. **参考区间拿全书硬套。** 同类场景的台词均长能差一倍（全书 17.3 字 vs 喝酒段 8.6 字）。
   对标必须按场景切。
5. **凭印象写人物设定。** 印象里「某角色几乎不开口」，索引一查是 360 条台词。
   设定一律用索引验证。
6. **例子集太薄。** 例子少，模型写出来就飘。宁厚勿薄。
7. **把非正文混进语料。** 作者设定草案、编者前言、制作信息会把统计带偏，
   抽文本时就剔除，只用来核对设定。
8. **视点分裂不分区。** 外传是另一个视角 / 另一种人称，混进同一套统计就全废。
9. **版本混排。** 文库版和 WEB 版文风不同，统计要标注来源，别混算。

## 二、工程层面的坑

10. **摘要模板不统一就开跑。** 格式不一致，二层没法机械合并，只能人工收拾。
11. **不保留标题层级。** 抽文本时丢掉 h1/h2/h3，分片和卷映射全要重新猜。
12. **分片跨版块。** 外传和主线切进同一片，摘要会把两种视点揉成一份。
13. **摘抄被模型改写。** 「原文文风样本」必须逐字，一旦被润色，例子集里就掺了模型的句子。
14. **不看覆盖率。** 模型跳读时不会报错，只会给你一份缺失中段的摘要。
    `03_merge_notes.py` 的片尾关键词回查能抓到这个。
15. **去重去多了。** 跨卷重复的事件要保留，只去重同卷内完全相同的字符串。
16. **不标统计口径。** 「对白占比 29.9%」如果来自 demo 语料而不是正文实测，
    模型会把它当硬指标。任何数字都写明来源。

## 三、写作层面的八种违和形态

| # | 形态 | 左错右对 |
|---|---|---|
| 1 | 自造词 | 从耳朵根 → 一摸脑袋；趴平 → 耷拉下来 |
| 2 | 一句多动作 + 精确部位 | 「两手在身侧攥了又松，后腰撞到桌角」→「本能地向后退却，却不知不觉间撞到了墙壁上」 |
| 3 | 修辞对仗 | 「从 A 到 B，再从 B 绕回 A」「我没 X，你有」 |
| 4 | 精确计量 | 「只剩一只手那么宽」→「近得能看清她睫毛上沾着的血渍」 |
| 5 | 光影编排 | 为情绪安排环境光「灯晃了一下，影子跟着抖，她把灯推远，光照不到她的脸了」 |
| 6 | 同一比喻用两次 | 一段里两次「煮熟的虾」 |
| 7 | 设定倒豆子 | 一句话交代物+谁给+何时+为何留+谁教的 |
| 8 | 连接词封口 | 「接着…然后…」「结果…」——用概括收尾而不是动作 |

**摘抄法则**：从原文搬句式必须**连主语一起搬**。
「X 把尾巴放到 Y 手心里」只抄后半截就变成「尾巴自己动了」。
凡是「物件+动作」句，先问这东西是谁在动。

## 四、指标目标值

| 指标 | 目标 | 说明 |
|---|---|---|
| 0 频探针倍数 | ≤ 1.05（>1.3 回去改） | 新造 4-gram 率 / 书留出基准。**只看倍数，不看绝对值**（基准随语料变） |
| 逐句 z（台词 / 叙述） | ≈ ±0.3，越接近 0 越像 | 负 = 比书平淡，正 = 比书生造 |
| 结构比值 | 接近同类书段中位 | 最弱的一层，只作参考；K≥200 才稳 |
| 门槛层 | 全部在同类参考段区间内 | 只判尺寸，不判像不像 |
| 一卷纪要长度 | 1800–3500 字 | 短了丢事件，长了模型读不完 |
| 一片摘要长度 | 900–1500 字 | 同上 |
| 覆盖率 | 每片读到片尾 | 片尾关键词命中率 > 1/4 |

## 五、已知弱点（别当硬判据）

- 结构层分离度依赖停用词剔除程度，弱分离时（书段 1.16 vs 打乱 0.91）不要下结论。
- 自动抓说话人准确率低于人工校对过的归属文件。
- 逐句层只看用字搭配，**看不出情节错**。
- 0 频探针会被新角色名抬高，所以 `verify.py` 里有「新专名检测」，
  会把新名字等长替换成书里的名字再算一遍。
