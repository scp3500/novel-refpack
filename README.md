# novel-refpack

把一本长篇小说（十万到几百万字）加工成两份轻量参考文件：
- `work/out/整书总结.md`（原作总结）：世界观、全卷分剧情、角色现状、伏笔、设定禁区 —— **锁住事实，防止吃书**。
- `work/out/例子.txt`（例子总结）：原文叙述腔调、分角色口癖、动作搭配表、零频黑名单 —— **锁住文风，贴近原作**。

本项目主要就是提炼这两份文件。字符 4-gram 统计等质检工作默认不做，纯属可选。

---

## 四种创作模式（你能用它做什么）

生成出文件后，**直接打开 txt / md，把内容复制粘贴到 ChatGPT、Claude 或 DeepSeek 聊天框里**，根据需求选用不同模式：

| 创作模式 | 怎么粘贴 txt / md | 适合场景 |
|---|---|---|
| **1. 原作同人与 IF 线** | **两份都粘**：前置粘贴《整书总结.md》（锁剧情设定），后置粘贴《例子.txt》（锁文风对白） | 写同人续写、IF 分歧线、支线补完，绝不崩人设与剧情 |
| **2. 纯文风原创仿写** | **只粘例子**：不粘原书剧情，只把《例子.txt》中的叙述腔和描写范例粘给模型当「文风滤镜」 | 写完全全新的原创故事，借用名作家的笔法与叙述节奏 |
| **3. 多文风正交融合** | **跨书拼接**：从 A 书提取动作叙述，从 B 书提取机智对白，组合粘贴到提示词中 | 捏出全新文学风格（如“硬汉动作白描 + 轻小说吐槽对白”） |
| **4. 反 AI 腔与特征过滤** | **只粘禁区**：直接把《例子.txt》底部的搭配雷区与零频禁用词粘到结尾作为负面提示词 | 无论写什么题材，直接封杀大模型的机械套话与公文腔 |

*(各模式的具体拼接示例与详细 Prompt 模板见 [docs/MODES.md](docs/MODES.md))*

## 怎么得到这两份文件

### 方式 A · 首选推荐：直接让当前 Agent 执行（零配置、免 API Key）

如果你正在使用 Coding Agent（如 Pi、Claude Code、Cursor 等）：
**无需配置任何 API Key 或模型端点，更不需要手动调参。**

当前模型本身具备子代理编排与读写能力。把书（`.epub` / `.txt`）放入目录后，直接对 Agent 发一句指令：

> **“帮我把《书名》处理成整书总结和例子集。先本地切片，再派子代理跑分片纪要并汇总生成成品。”**

Agent 会自动在后台完成切片、派发子代理并行提取、并总装生成交付文件。

---

### 方式 B · 备选方案：独立脚本 + 外部 API（脱离 Agent 批量挂机）

若脱离了交互式 Agent 窗口，需在服务器后台批量跑任务：

```bash
git clone <this-repo> && cd novel-refpack
cp config/project.example.json config/project.json  # 填入书名、路径、API 或本地模型端点

python scripts/12_run_all.py                        # 全平台一键执行（Windows 推荐 python -X utf8）
python scripts/12_run_all.py --no-llm               # 仅运行本地离线部分（抽文本、分片、建索引）
```

## 拿到的结果怎么用（直接复制粘贴）

产物输出在 `work/out/` 目录下，用记事本或编辑器打开，**直接复制粘贴文本到你的 AI 对话框中**：

```text
[系统提示词 / 第一条消息]
你是一名专业小说作家。必须严格遵守以下事实设定或笔法规则：
--- 直接复制粘贴《整书总结.md》或《例子.txt》中的对应片段 ---

[你的任务 / 第二条消息]
请帮我写一段正文：[输入你具体的续写剧情要求或原创故事设想]
```
