# style-fit · 从语料拟合文风，按它写，再验收

## 什么时候用

- 要仿写某本书 / 某个作者的笔法
- 稿子被说「有 AI 味」但说不清哪儿不对
- 要给提示词补「不许怎么写」的硬规则
- 要判断一段生成文本到底像不像原文

## 三条底层判断（这个工具包全部价值的来源）

### 1 · 边际统计测不出「像不像」，只能当筛子

句长、对白占比、段长、标点率这些**段级聚合量**，对「把段落打乱」完全免疫——实测 AUC 恰好 **0.500**。
一篇文章把段落全部打乱，这些指标一个都不变。

**推论：任何「把整段压成一个数」的指标，原理上无法判断顺序对不对、像不像。只能用来判尺寸在不在范围内。**

### 2 · 唯一有效的验证负样本是「内容保留打散」

不需要人工标注、不需要另一个模型盲判。做法：把语料里真实的段落原样打乱顺序再拼回去——同词、同句、同长度，只有顺序变了。

- 边际统计对它免疫 → 能分开的指标，必然在测结构
- 实测：相邻段实词重合（jacCt）在真书上是打乱样本的 **2–3 倍**，AUC **0.79**

### 3 · 搭配比词更致命

写手「造词」比「造搭配」少得多。真实情况是：**每个词他都认识，但配错了动词或方位。**

```
"帽檐下"   → 写成「帽子外面」     （0 次）
"趴下"     → 写成「趴这儿」       （0 次）
"一摸脑袋" → 写成「摸了摸脑袋」   （0 次）
"推开"     → 写成「推了推」       （「推了推」全是推箱子推眼镜）
```

**所以最高杠杆的一层工具是「搭配表」，不是「词表」。**

## 工作流

### 第一步 · 建索引

```bash
python stylefit/build_index.py --corpus chunks --out cache/mybook \
    [--attrib attrib.json] [--names 甲,乙,丙] [--config config/stylefit]
```

归属文件可选（格式 `[{who,text}]` 或 `{who:[line]}`）。没有就用「名字+说话动词+引号」自动抓，准确度低一些。

产出 `index.json`：人物×功能桶台词、描写意图样本、**搭配表**、用词表、零频黑名单、场景词典、场景片段、统计靶。

### 第二步 · 写之前查

```bash
python stylefit/query.py --index cache/mybook/index.json --colloc        # 全部搭配概念
python stylefit/query.py --index ... --colloc 耳朵的动作                 # 0 的那项就是雷区
python stylefit/query.py --index ... --who 白夜 --func 让步接受          # 这个人在这种处境怎么说话
python stylefit/query.py --index ... --why 脸红                          # 这个意图书里怎么写
python stylefit/query.py --index ... --scene 亲密                        # 同类场景的真实片段
python stylefit/query.py --index ... --dict 亲密                         # 这类场景实际用的词
python stylefit/query.py --index ... --words                             # 用词表 + 零频黑名单
python stylefit/query.py --index ... --stats                             # 统计靶
```

**这一步不能省。** 凡是「这个动作该配哪个动词」「这个人在这种处境会说什么」的疑问，答案都在书里，不在你的语感里。

### 第三步 · 写

按下面的「写作规矩」写。

### 第四步 · 验收

```bash
python stylefit/verify.py --text 稿.txt --corpus chunks --out cache/mybook \
    --ref-pattern '(关键词正则)'
```

| 层 | 测什么 | 目标 |
|---|---|---|
| **门槛** | 段级边际统计在不在语料范围内 | 全部在范围内 |
| **结构** | 自打乱比值 | 接近「同类书段中位」 |
| **逐句** | 字符 4-gram 条件归一化 z | 均值 ≈ ±0.3，越接近 0 越像 |
| **0 频探针** | 新造 4-gram 率 | 倍数接近 **1.00**（≤1.05 良好） |

`--ref-pattern` 很重要：**参考区间要按你正在写的场景类型切**，不能拿全书硬套。

## 八种违和形态（写完自查）

| # | 形态 | 例子（左错右对） |
|---|---|---|
| 1 | **自造词** | 从耳朵根 → 一摸脑袋；趴平 → 耷拉下来 |
| 2 | **一句塞多动作 + 精确部位** | 「两手在身侧攥了又松，后腰撞到桌角」→「本能地向后退却，却不知不觉间撞到了墙壁上」 |
| 3 | **修辞对仗** | 「从 A 到 B，再从 B 绕回 A」「我没 X，你有」 |
| 4 | **精确计量** | 「只剩一只手那么宽」→「近得能看清她睫毛上沾着的血渍」 |
| 5 | **光影编排**（为情绪安排环境） | 「灯晃了一下，影子跟着抖，她把灯推远，光照不到她的脸了」 |
| 6 | **同一比喻用两次** | 一段里两次「煮熟的虾」 |
| 7 | **设定倒豆子** | 一句话交代物+谁给+何时+为何留+谁教的 |
| 8 | **连接词封口** | 「接着…然后…」「结果…」（用概括收尾而不是动作） |

## 摘抄法则

**从原文搬句式时，必须连主语一起搬。**

```
原句：雷蕾一边陶醉地喝奶，一边主动将尾巴轻轻地放在了宁柠的手心里。   （主语=雷蕾）
只抄后半截 → 那条尾巴轻轻地放在了宁柠的手心里。                    （尾巴自己动了，崩）
```

凡是「物件+动作」的句子，先问：**这东西是谁在动？** 没有施动者的动作句一律重写。

**物件出现要有来源、消失要有去处。** 怀里抱着黑板，得先写一句「放在一边」，它才能在后面掉下去。

## 人物设定要用索引验证，不要凭印象

```
印象/提示词写的：      索引查出来的：
「某角色几乎不开口」     台词 360 条，写在『』里的只 16 条（4%）
「这人句子偏长有条理」   让步只有「嗯。」「好。」；命令句是「别+动词」两三个字
「好吧是谁的口头禅」     甲 84 次 : 乙 15 次 —— 别给错人
```

## 写作规矩

1. 一句只写一个动作，方位模糊
2. 距离写后果，不写数字
3. 环境只做背景，不许参与情绪
4. 同一个比喻全篇一次
5. 物件要有来源和去处
6. 摘抄连主语
7. 不用连接词封口
8. 全篇要有 1–2 个旁证角色（名字/声音/动静都算），不要两人真空
9. 长句是「3–4 个具体分句并列」，不是「一句加一堆解释」
10. 写完必须跑一遍 `verify.py`，0 频探针倍数 > 1.3 就回去改

## 已知弱点

- **结构层最弱**。分离度依赖 `cset` 剔除人名/停用词的程度，且 K 要 ≥200 才稳。弱分离时不要当硬判据。
- **自动抓说话人的准确率低于归属文件。** 有归属文件就用。
- **逐句层只看用字搭配，不看内容合不合理。** 它抓不出「情节错」。
- **0 频探针是相对量。** 基准随语料变，永远看**倍数**，不看绝对值。
